      新しいプロンプト
      
                        
                        
      
                            
                                画像から下書きを作る
                                お手本の画像の作風を AI が読み取ります（1 回ごとに少額の料金）
                            
                            
      
                                作風（線・塗り・色づかい・質感・光など）を言葉にした下書きを、下のタイトルと本文に入れます。
                                写っている人物や物は本文に入れません。

                            実際の請求額は各プロバイダーの管理画面で確認してください。
                            このツール以外で使った分は含みません。
                        
      
                    
      

                    
      
                        
      月の予算

      失敗した変換（新しい順）
      
                        
                    
      
                    
      
                        失敗でも料金が記録されているものは、課金された、またはその可能性があるものです。
                        クリアしても、料金の記録と回数は消えません（一覧から消すだけです）。
                    
      
                    
        
                
        
            
        
        
        

        
        
        
            
        
                
        
                    
        API キー
        
                    
        
                        
        API キーを使う前に、必ず次の 2 つを行ってください
        
                        
          
                            
        • 
                                キーには短い有効期限を付ける。長期・無期限のキーは使わない。
                                有効期限を選べる場合は、使う期間だけの短い期限にします。選べない場合は、使い終わったら各社の管理画面でキーを無効にし、
                                次に使うときに作り直します。使っていないキーを残さないでください。
                            
          • 
                            
        • 
                                各社の管理画面で、支払いの上限を必ず設定する。
                                月の利用上限（予算の上限）を設定し、前払い（プリペイド）の場合は自動チャージを切っておきます。
                                上限を設定していないと、キーが漏れたときや操作を誤ったときに、請求が止まりません。
                                このアプリの「月の予算」は目安を知らせるだけで、請求を止める力はありません。
                            
          • 
                        
        
                    
        
                    
        
                        キーはこの PC の .env ファイルに保存され、保存するとすぐ使えます。
                        登録後は末尾 4 文字だけを表示し、キーの全体を画面に出すことはありません。
                    
        
                    
          
                
          

                
          
                    
          データの置き場
          
                    
          
                        プロンプト・履歴・画像を置くフォルダーです。変更は、アプリを次に起動したときから効きます。
                    
          
                    
          
                        
                            
          今の置き場
          
                            
          既定の場所
          
                                  
                    
          
                    
          
                    
          
                    
          
                        
          
                            
                            
                            
                        
          
                    
          
                    
            
                        
          • 空のフォルダー（または、まだないフォルダー）を指定すると、今のデータをそこへ写します。元の場所のデータは消しません。
            • 
                        
          • PromptShop のデータがすでに入っているフォルダーを指定すると、写さずに、そのデータを使います。
            • 
                        
          • API キーのファイルは移しません（今の場所のままです）。
            • 
                        
          • クラウドと同期するフォルダーや、ネットワーク上のフォルダーは避けてください。データベースが壊れることがあります。
            • 
                        
          • 「既定に戻す」は、データを写しません。既定の場所に残っているデータをそのまま使います。

          PromptShop について
          
                    
          PromptShop
          
                    
          
                        画像変換のプロンプトを登録・検索し、選んだ画像に OpenAI・Grok・Gemini の API で適用して、
                        結果を見比べて管理するツールです。この PC の中だけで動きます。

          使い方
          
                    
          
                        1. はじめに（API キーの登録）
                        
            
                            
          • 「設定」タブで、使いたいプロバイダーの API キーを入れて「保存」を押します。1 社だけでも使えます。
            • 
                            
          • キーは各社の管理画面で発行します。発行と利用には、各社への登録と支払い方法の設定が必要です。
            • 
                            
          • キーには短い有効期限を付け、各社の管理画面で支払いの上限を必ず設定してください（上の「必ず守ってほしいこと」）。
            • 
                            
          • 登録後は末尾 4 文字だけが表示されます。キーが未登録のプロバイダーは選べません。
            • 
                        
          
                    
          
                    
          
                        2. 画像を変換する（「変換」タブ）
                        
            
                            
          • 左の枠に画像をドロップするか、枠を押してファイルを選びます（PNG / JPEG / WebP、20 MB まで）。
            • 
                            
          • 「画像から選ぶ」で、前に取り込んだ画像や変換済みの画像を選び直せます。「元画像」「変換済み画像」「すべて」で切り替えます。
            • 
                            
          • ジャンルとタイトルでプロンプトを選びます。本文はその場で書き換えられます（登録済みのプロンプトは変わりません）。プロンプトを選ばずに本文を直接書いても変換できます。
            • 
                            
          • プロバイダーを選んで「変換」を押します。1〜2 分かかることがあります。1 回押すごとに料金がかかります。
            • 
                            
          • 「縦横比維持」を外すと、出力の形をプロバイダーに任せます。プロンプトに形（正方形など）を書いたときに使います。
            • 
                            
          • 結果は元画像と左右に並びます。画像を押すと拡大し、「保存」でファイルに保存できます。
            • 
                            
          • 選んでいる画像は、名前の下の「この画像を削除」（2 回押し）で消せます。
            • 
                        
          
                    
          
                    
          
                        3. 結果を管理する（「ギャラリー」タブ）
                        
            
                            
          • 変換結果が新しい順に並びます。お気に入り、評価、プロバイダー、プロンプト、作例で絞り込めます。
            • 
                            
          • ♥ でお気に入り、★ で 1〜5 の評価を付けます。付いている星をもう一度押すと未評価に戻ります。
            • 
                            
          • サムネイルを押すと詳細が開き、元画像との比較、使ったプロンプト、変換の連鎖（どの画像から作ったか）が見られます。
            • 
                            
          • 「再変換」で、その結果を元画像にして別のプロンプトを重ねられます。
            • 
                            
          • 「作例に登録」すると、変換画面で同じプロンプトとプロバイダーを選んだときに見本として出ます。
            • 
                            
          • 「削除」は 2 回押しです。画像は消えますが、履歴と料金の記録は残ります。元には戻せません。
            • 
                        
          
                    
          
                    
          
                        4. プロンプトを登録・編集する（「プロンプト」タブ）
                        
            
                            
          • 「新規」を押し、タイトル・ジャンル・本文を入れて「保存」を押します。
            • 
                            
          • 登録済みのものを直すときは、一覧の行を押します。右の欄で編集と削除ができます。
            • 
                            
          • 一覧は、ジャンルとキーワードで絞り込めます。
            • 
                            
          • 「ジャンルの管理」を開くと、ジャンルの追加・改名・並べ替え・削除ができます。ジャンルを消しても、プロンプトは「未分類」で残ります。
            • 
                        
          
                    
          
                    
          
                        5. 画像からプロンプトの下書きを作る
                        
            
                            
          • 「プロンプト」タブで「新規」を押し、「画像から下書きを作る」を開きます。
            • 
                            
          • お手本の画像、読み取りに使うプロバイダー、本文の言語を選んで「作風を読み取る」を押します。1 回ごとに料金がかかります。
            • 
                            
          • 読み取るのは作風（線・塗り・色づかい・質感など）だけです。写っている人物や物、構図の指定は入りません。必要なら手で書き足してください。
            • 
                            
          • 下書きは入力欄に入るだけです。「保存」を押すまで登録されません。
            • 
                        
          
                    
          
                    
          
                        6. 料金を確認する（「料金」タブ）
                        
            
                            
          • 今月の概算の合計、プロバイダー別の内訳、月ごとの合計、失敗した変換が見られます。今月の合計は画面の右上にもいつも出ています。
            • 
                            
          • 月の予算を入れておくと、合計が予算に達したとき、変換の前に確認が出ます（変換は止めません）。
            • 
                            
          • 「失敗した変換」の「一覧をクリア」は、一覧から消すだけです。料金の記録と回数は残ります。
            • 
                        
          
                    
          
                    
          
                        7. データの置き場とバックアップ
                        
            
                            
          • 置き場は「設定」タブの「データの置き場」で変えられます。変更は、次に起動したときから効きます。
            • 
                            
          • プロンプト・履歴・画像は、上の「データの置き場」のフォルダーに入っています。アプリを閉じてから、フォルダーごと別の場所へ写せばバックアップになります。
            • 
                            
          • API キーは「API キーのファイル」に入っています。このファイルは人に渡さないでください。
            • 
                        
          
                    
          
                    
          
                        8. 困ったとき
                        
            
                            
          • 「API キーが正しくありません」: 「設定」タブでキーを登録し直します。
            • 
                            
          • 「利用上限に達したか、残高が不足しています」: 各社の管理画面で、残高と上限を確認します。
            • 
                            
          • 「コンテンツポリシーにより拒否されました」: 画像かプロンプトが各社の決まりに合っていません。内容を変えて試します。
            • 
                            
          • 「別の変換を実行中です」: 前の変換が終わるまで待ちます。
            • 
                            
          • 変換中に窓を閉じようとすると 1 回目は止められます。10 秒以内にもう一度閉じると終了します（その変換の結果は残りませんが、料金はかかっていることがあります）。
