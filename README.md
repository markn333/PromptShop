# PromptShop

画像変換用のプロンプト（フィルター、画風変換など）を保存しておき、元画像に当てて変換するための、自分の PC の中だけで動くツールです。

- プロンプトにタイトルとジャンルを付けて保存し、プルダウンから呼び出せます。
- 元画像とプロンプトを選んで変換し、元画像と結果を左右に並べて見比べられます。
- 変換結果にお気に入りと評価を付けて管理できます。どの画像からどのプロンプトで作ったかも、あとからたどれます。
- 変換には OpenAI・Grok（xAI）・Gemini の API を使います。月額の契約は要りませんが、**変換 1 回ごとに料金がかかります**。
- 今月いくら使ったか（概算）を画面で確認でき、月の予算も設定できます。

---

## 1. 必要なもの

| もの | 内容 |
|------|------|
| OS | Windows 10 / 11 |
| Python | 3.10 以上（`python --version` で確認） |
| API キー | OpenAI・xAI・Google のうち、使いたいものを 1 つ以上。各社の管理画面で発行し、支払い方法を登録しておく |
| ブラウザ | Chrome、Edge など |

## 2. 初回セットアップ

アプリ版（`PromptShop.exe`）を使うだけなら、この章は要りません。ブラウザ版を使う場合と、exe を作り直す場合に行います。

PromptShop のフォルダーでコマンドプロンプト（または PowerShell）を開き、次を 1 回だけ実行します。

```
pip install -r requirements.txt
```

## 3. 起動と終了

PromptShop には、同じ画面を 2 通りの方法で開く版があります。**ふだん使うのは 3.1 のアプリ版です。**

### 3.1 アプリ版（PromptShop.exe）

| 操作 | 方法 |
|------|------|
| 起動 | `dist\PromptShop.exe` をダブルクリックする。数秒で専用の窓が開く（黒い窓もブラウザも出ない） |
| 終了 | 窓を閉じる |

- exe は 1 個のファイルで、Python を入れていない状態でも動きます。好きな場所に移したり、ショートカットを作ったりして構いません。
- 初回は、Windows が「PC が保護されました」という警告を出すことがあります（署名のない exe のため）。「詳細情報」→「実行」で起動できます。
- 同時に 2 つは起動できません（2 つ目は「すでに起動しています」と出て終わります）。
- 変換の実行中に窓を閉じようとすると、いったん取り消して知らせを出します。10 秒以内にもう一度閉じると終了します（その場合、課金されていても履歴には残りません）。
- 画像をクリックすると、窓の中で大きく表示されます。もう一度クリックすると原寸になり、「保存」で PC に保存できます。
- **データの置き場は、3.2 のブラウザ版とは別です**（7 章）。

### 3.2 ブラウザ版（run.bat）

Python が入っている PC で、ブラウザのタブで使う版です。2 章のセットアップが要ります。

| 操作 | 方法 |
|------|------|
| 起動 | `run.bat` をダブルクリックする。黒い窓（コンソール）が開き、少し待つとブラウザに画面が出る |
| 終了 | 黒い窓で Ctrl+C を押すか、窓を閉じる |
| 画面をもう一度開く | ブラウザで `http://127.0.0.1:8765/` を開く |

- 黒い窓を閉じると PromptShop は止まります。使っている間は開いたままにしてください。
- 初回の起動時に、データを置く `data` フォルダーが自動で作られます。

## 4. API キーの登録

**API キーを使う前に、必ず次の 2 つを行ってください。**

- **キーには短い有効期限を付ける。長期・無期限のキーは使わない。** 有効期限を選べる場合は、使う期間だけの短い期限にします。選べない場合は、使い終わったら各社の管理画面でキーを無効にし、次に使うときに作り直します。使っていないキーを残さないでください。
- **各社の管理画面で、支払いの上限を必ず設定する。** 月の利用上限（予算の上限）を設定し、前払い（プリペイド）の場合は自動チャージを切っておきます。上限を設定していないと、キーが漏れたときや操作を誤ったときに、請求が止まりません。このアプリの「月の予算」は目安を知らせるだけで、請求を止める力はありません。

1. 画面上部の「設定」タブを開きます。
2. 使いたいプロバイダーの欄に API キーを貼り付けて「保存」を押します。
3. 「登録済み（末尾 xxxx）」と表示されれば完了です。起動し直す必要はありません。

- キーはこの PC の `.env` ファイルに保存されます。画面には末尾 4 文字しか出ません。
- 保存の時点では、キーが正しいかどうかは確かめません。誤っていた場合は、最初の変換で「API キーが正しくありません」と表示されます（料金はかかりません）。
- 使わないプロバイダーは空のままで構いません。キーを登録していないプロバイダーは、変換画面で選べません。
- **API キーは他人に見せないでください。** チャットやメールにも貼らないでください。

## 5. 使い方

### 5.1 プロンプトを登録する（「プロンプト」タブ）

1. 「新規」を押し、タイトル・ジャンル・本文を入れて「保存」を押します。
2. ジャンルは、同じ画面の「ジャンルの管理」で追加・改名・並べ替え・削除ができます。ふだんは閉じているので、見出しを押して開きます。ジャンルを削除しても、所属していたプロンプトは「未分類」として残ります。
3. 一覧は、ジャンルとキーワード（タイトル・本文）で絞り込めます。
4. 登録済みのプロンプトを直すときは、一覧の行（右端に「編集」と出ています）を押します。右の欄に内容が出るので、直して「保存」を押します。「削除」もそこでできます。
5. プロンプトを開くと、「これを使った変換結果」が下に並びます。

#### 画像からプロンプトを作る（作風の読み取り）

お手本にしたい画像を AI に見せて、その作風を言葉にしたプロンプトの下書きを作れます。

1. 「プロンプト」タブで「新規」を押し、入力欄のいちばん上にある「画像から下書きを作る」を押して開きます（既存のプロンプトを編集している間は出ません）。「画像ファイルを選ぶ」を押してお手本の画像を選びます。取り込み済み・変換済みの画像から選ぶこともできます。
2. 読み取りに使うプロバイダーと、本文の言語（日本語 / 英語）を選びます。
3. 「作風を読み取る」を押します。数秒から 1 分ほどで、タイトルと本文の下書きができます。
4. 入力欄が空なら、下書きがそのまま入ります。書きかけの内容があるときは上書きしないので、「この下書きで入力欄を置き換える」を押してください。
5. 内容を確かめ、必要なら手直しして「保存」を押します。**保存を押すまで、プロンプトには登録されません。**

- 読み取るのは作風（線、塗り、色づかい、質感、光など）だけです。写っている人物や物は本文に入れません（入れると、変換のときに元画像の中身まで変わってしまうためです）。
- **1 回ごとに料金がかかります**（目安は 6 章）。失敗しても料金がかかる場合があります。
- AI の書く文章は毎回少し変わります。気に入らなければ、もう一度読み取るか、別のプロバイダーで試してください。
- ここで選んだ画像ファイルは、変換画面の元画像の一覧にも出ます。

### 5.2 変換する（「変換」タブ）

1. 元画像を枠にドロップするか、枠をクリックして選びます（PNG / JPEG / WebP、20 MB まで）。前に取り込んだ画像や変換結果は、下のサムネイルから選べます。
2. ジャンル → タイトルの順にプルダウンで選ぶと、本文が入ります。本文はその場で書き換えられます（保存済みのプロンプトは変わりません）。プロンプトを選ばずに、本文を直接書いても変換できます。
3. プロバイダーを選び、「変換」を押します。1〜2 分かかることがあります。
4. 終わると、元画像と変換結果が左右に並びます。画像をクリックすると原寸で開きます。
5. 結果の下で、お気に入り（♥）・評価（★）を付けたり、「これを元画像にして再変換」で続けて変換したりできます。
6. プロンプトとプロバイダーを選ぶと、その組み合わせで登録した「作例」がサムネイルで出ます（登録の方法は 5.3）。仕上がりの見当を付けるのに使えます。

- 元のファイルには手を加えません。取り込んだ画像の写しを `data` フォルダーに保存して使います。
- 出力の縦横比は、元画像にいちばん近いものを自動で選びます（元画像とまったく同じ大きさにはなりません）。
- 「縦横比維持」のチェックを外すと、出力の形をプロバイダーに任せます。プロンプトに「1:1 の正方形で」のように形を書いたときに使います。形を書かなければ、プロバイダーの既定の形（正方形になることが多い）になります。アプリを開き直すと、チェックは入った状態に戻ります。
- 失敗した場合は、結果の位置に理由が出ます。**自動でやり直すことはありません。**

### 5.3 結果を管理する（「ギャラリー」タブ）

- 変換結果が新しい順に並びます。お気に入りのみ・評価・プロバイダー・プロンプトで絞り込めます。
- サムネイルの下に、その結果を作ったプロンプトのタイトルとプロバイダーが出ます。タイトルは変換した時点のものです。
- 「作例に登録」を押すと、その変換結果が、使ったプロンプトとプロバイダーの見本になります。変換画面で同じプロンプトとプロバイダーを選ぶと表示されます。もう一度押すと解除できます。プロンプトを選ばずに本文を直接入力して作った結果は、作例にできません。
- サムネイルを押すと詳細が開き、左右の比較、使ったプロンプト（実行した時点の本文）、最初の元画像からの変換の流れが見られます。
- 「削除」は 2 回押すと実行されます。画像ファイルは消えますが、変換の履歴と料金の記録は残ります。**削除した画像は元に戻せません。**
- 取り込んだ元画像（お手本として取り込んだ画像を含む）は、ギャラリーには出ません。削除するときは、「変換」タブの「画像から選ぶ」でその画像を選び、画像の下に出る「この画像を削除」を 2 回押します。

### 5.4 料金を確認する（「料金」タブ）

- 今月の合計、プロバイダー別の内訳、月ごとの合計、失敗した変換の一覧が見られます。合計と回数には、作風の読み取りの分も入ります（その分だけの料金と回数も、合計の下に出ます）。今月の合計は、画面右上にもいつも出ています。
- 月の予算（USD）を設定できます。今月の合計が予算に達すると、変換の前に確認が出ます。「それでも変換する」を押せば変換できます（予算は目安で、変換を止めるものではありません）。
- 月の区切りは、この PC の時刻で毎月 1 日 0 時です。
- 「失敗した変換」の「一覧をクリア」を 2 回押すと、一覧が空になります。料金の記録と回数は消えません。

### 5.5 データの置き場を変える（「設定」タブ）

1. 「設定」タブの「データの置き場」で、新しいフォルダーの場所（例: `D:\PromptShopData`）を入れて「変更」を押します。
2. 空のフォルダー（または、まだないフォルダー）なら、今のデータをそこへ写します。元の場所のデータは消しません。
3. アプリを閉じて、もう一度起動すると、新しい場所を使い始めます。

- PromptShop のデータがすでに入っているフォルダーを指定すると、写さずに、そのデータを使います。
- API キーのファイルは移しません。
- クラウドと同期するフォルダーや、ネットワーク上のフォルダーは避けてください（データベースが壊れることがあります）。
- 外付けドライブを置き場にして、つながずに起動した場合は、既定の場所で起動して知らせを出します。つないでから起動し直してください。
- 切り替えたあと、元の場所のデータが要らなければ、エクスプローラーで手で消してください（アプリは消しません）。
- 画面に出るフォルダーの場所は、Windows のアカウント名が写らないよう `%APPDATA%\PromptShop\data` のような書き方にしてあります。エクスプローラーのアドレス欄にそのまま貼ると開けます。

### 5.6 ヘルプ（「ヘルプ」タブ）

- アプリのバージョン、データの置き場、使い方、免責事項、ライセンスが見られます。
- **免責事項は、使い始める前に読んでください。** API の料金はすべて利用者の負担で、作者は責任を負いません。

## 6. 料金について

**画面の金額は、このツールが変換のたびに記録した概算です。実際の請求額は、各プロバイダーの管理画面で確認してください。**

| プロバイダー | モデル | 1 回あたりの目安 | 計算方法 |
|-------------|--------|-----------------|---------|
| OpenAI | `gpt-image-2.6-sunburst` | $0.05〜0.07 | 応答に含まれる使用量 × 単価 |
| Grok（xAI） | `grok-imagine-image-2.0` | $0.06 | 固定（出力 $0.04 + 入力画像 $0.02。入力画像の単価は公表されていないため仮の値） |
| Gemini | `gemini-nano-banana-2.1` | 約 $0.04 | 応答に含まれる使用量 × 単価 |

「画像からプロンプトを作る」（作風の読み取り）は、画像変換とは別の、文章を書くモデルを使います。API キーは画像変換と共通です。

| プロバイダー | モデル | 1 回あたりの目安 | 計算方法 |
|-------------|--------|-----------------|---------|
| OpenAI | `gpt-6.1-terra` | $0.01 未満の見込み | 応答に含まれる使用量 × 単価 |
| Grok（xAI） | `grok-4.7` | $0.01 前後の見込み | 応答に含まれる料金（なければ使用量 × 単価） |
| Gemini | `gemini-3.8-flash` | $0.01 未満の見込み | 応答に含まれる使用量 × 単価 |

- 作風の読み取りの目安は、2026-11-20 時点の単価からの見積もりです（実際の API ではまだ確かめていません）。モデルが考える量によって増えることがあります。実際にかかった概算は、読み取りのたびに画面に出ます。
- Gemini の `gemini-3.8-flash` は、2027 年 1 月 1 日から単価が 2 倍になると公式に書かれています。そのときは `app/config.py` の単価を書き換えてください。
- 目安は 2026-11-19 時点の単価と、実際に変換した結果によるものです。値上げ・値下げがあった場合は `app/config.py` の単価を書き換えてください。
- **失敗しても料金がかかる場合があります。** たとえば Gemini は、出力が安全フィルターで止められても課金されます。応答が時間内に返らなかった場合も、課金されている可能性があります。こうした場合は、失敗として記録したうえで料金にも含めます。
- このツール以外で同じ API キーを使った分は、画面の金額に含まれません。
- 使うモデルは、`.env` に次の行を足すと変えられます（起動し直すと反映されます）。

  ```
  OPENAI_IMAGE_MODEL=モデル名
  XAI_IMAGE_MODEL=モデル名
  GEMINI_IMAGE_MODEL=モデル名
  OPENAI_TEXT_MODEL=モデル名
  XAI_TEXT_MODEL=モデル名
  GEMINI_TEXT_MODEL=モデル名
  ```

  `..._IMAGE_MODEL` は画像変換、`..._TEXT_MODEL` は作風の読み取りに使うモデルです。

## 7. データの保存場所とバックアップ

データを置くフォルダーは、版によって違います。**2 つの版はデータを共有しません。**

| 版 | データを置くフォルダー |
|----|----------------------|
| アプリ版（`PromptShop.exe`） | `%APPDATA%\PromptShop`（エクスプローラーのアドレス欄に貼り付けると開く） |
| ブラウザ版（`run.bat`） | PromptShop のフォルダー（`run.bat` のある場所） |

そのフォルダーの中身は、どちらの版も同じです。

| 場所 | 中身 |
|------|------|
| `data/promptshop.db` | プロンプト、ジャンル、変換の履歴、料金の記録、予算 |
| `data/sources/` | 取り込んだ元画像 |
| `data/results/` | 変換結果 |
| `data/thumbs/` | 一覧用の縮小画像 |
| `.env` | API キー |
| `promptshop.log` | アプリ版のログ（起動・終了・エラーの記録。API キーは書かない） |
| `webview/` | アプリ版の窓の部品が使う作業用フォルダー（消しても作り直される） |

- バックアップは、PromptShop を終了してから `data` フォルダーを丸ごとコピーします。戻すときも、終了した状態でフォルダーごと置き換えます。
- `.env` と `data` は Git の管理対象から外してあります。
- 変換結果を別の用途に使うときは、画像をクリックして大きく表示し、「保存」を押してください。
- アプリ版を別の PC に移すときは、exe と、`%APPDATA%\PromptShop` フォルダーの両方を写します。

## 8. 困ったとき

| 症状 | 対処 |
|------|------|
| アプリ版が起動しない、すぐ終わる | `%APPDATA%\PromptShop\promptshop.log` の末尾を確認する。窓が出る前に失敗した場合は、理由を書いたメッセージが出る |
| アプリ版の窓が真っ白のまま | Windows の「Microsoft Edge WebView2 ランタイム」が入っていない可能性がある（Windows 11 には最初から入っている）。Microsoft の配布ページから入れる |
| `run.bat` を実行しても画面が出ない | 黒い窓のメッセージを確認する。`No module named ...` と出ていれば、2 章のセットアップを実行する |
| 黒い窓がすぐ閉じる、または「ポートが使われている」という内容のエラーが出る | すでに PromptShop が起動していないか確認する。別のソフトが 8765 番を使っている場合は、コマンドプロンプトで `run.bat --port 8770` のように別の番号を指定し、表示された URL を開く |
| 「サーバーに接続できません」と出る | 黒い窓を閉じていないか確認し、`run.bat` で起動し直す |
| 変換ボタンが押せない | ボタンの横に理由が出る（API キー未登録 / 元画像なし / 本文なし） |
| 「API キーが正しくありません」と出る | 設定タブでキーを登録し直す |
| 「利用上限に達したか、残高が不足しています」と出る | 各プロバイダーの管理画面で、残高と利用上限を確認する |
| 「コンテンツポリシーにより拒否されました」と出る | 画像またはプロンプトの内容が、プロバイダーの規約で断られている。内容を変える |
| 「別の変換を実行中です」と出る | 変換は同時に 1 件だけ。前の変換が終わるのを待つ |
| 更新したのに画面が古い | ブラウザで再読み込みする（Ctrl+F5） |

ブラウザを自動で開きたくない場合は、`run.bat --no-browser` で起動します。

## 9. 安全のための決まり

- PromptShop は、この PC からしか開けません（`127.0.0.1` のみで待ち受けます）。ほかの PC やインターネットからは見えません。
- ほかのサイトのページから PromptShop を勝手に操作すること（API キーの書き換えや、意図しない変換）はできないようにしてあります。
- 変換ボタン 1 回につき、API の呼び出しは 1 回だけです。失敗しても自動ではやり直しません。変換中はボタンが止まり、同時に 2 件は動きません。
- API キーは、画面・ログ・履歴に出しません。

## 10. できないこと

- 複数の画像や複数のプロンプトをまとめて変換すること
- 元画像を使わずに、文章だけから画像を作ること
- 各プロバイダーの実際の請求額を取得すること

## 開発者向け

| 項目 | 内容 |
|------|------|
| 構成 | Python（FastAPI、SQLite）+ ブラウザ画面（HTML / CSS / JavaScript。ビルド不要） |
| 仕様 | `SPEC.md` |
| 自動テスト | `python -m pytest`（偽のプロバイダーと一時フォルダーを使う。実際の API は呼ばず、`data` と `.env` にも触れない） |
| 設定値 | `app/config.py`（ポート、上限、モデル ID、単価） |
| アプリ版をソースから起動 | `pip install -r requirements-desktop.txt` のあと `python -m app.desktop`（データはブラウザ版と同じ、プロジェクトのフォルダーを使う） |
| exe の作り直し | `build_exe.bat`（`dist\PromptShop.exe` ができる。1〜2 分かかる）。コードを直したあとは作り直さないと exe に反映されない |
| データの置き場を変える | 環境変数 `PROMPTSHOP_HOME` にフォルダーを指定する（確認用に、本物のデータと別の場所で動かすときに使う） |
